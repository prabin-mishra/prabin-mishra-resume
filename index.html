Projects

Five builds, and what they actually changed.

The work behind the timeline, each one as a hiring manager reads it: the problem, what I did about it, and the number at the end.

Flagship Epicor · 2022 – present · Product Owner

The BisTrack API platform — ~6,000 endpoints, authored with an AI agent

Problem
A distribution ERP that can't be integrated is a ceiling. Customers wanted their own systems on top of it, partners wanted to extend it, and the business needed a composable / headless path — but the ERP's capability was locked behind the UI.
What I did
Led design → specification → delivery of the BisTrack API platform across 1,000 API groups, then built an AI agent that automates endpoint analysis and specification authoring so a surface that size could actually be specified by one product owner.
Outcome
In controlled release, with a pilot customer already seeing success — the full ERP exposed for integrations, partner extensibility and composable / headless ERP, with the design cycle compressed by the agent rather than by cutting scope.

API platformComposable ERPAI agentDeveloper experience

Epicor · 2021 – present · Product Owner

On-prem → cloud SaaS: migrating a live distribution ERP

Problem
A legacy on-premise ERP with 500–2,000 global customers running their warehouses, yards and order books on it. None of them can afford a bad migration, and none of them move on the same schedule.
What I did
Owned the vision, roadmap and 1,400+ user-story backlog, sequencing the migration with C-suite / VP stakeholders across Product, Engineering and Sales. Built the team that carried it — business analysts and a designer moving legacy features onto the new Web UX — and trained them to analyze and implement new requirements themselves; directed 10–20 engineers through planning, refinement and release; onboarded appliances and rolled goods as new categories once the web platform could carry them.
Outcome
The web product is live at 50+ branches across 20+ customers. Order creation ~7% faster, journey planning +4%, duplicate stock receipts eliminated, EDI stock-receipt creation improved — and two new revenue categories live on it.
